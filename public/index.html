TAPSPRITE

下载与手册

这不是控制台。脚本、截图、取色都在电脑客户端里。这个网页只放安装包和命令说明。

电脑客户端

Windows。下发脚本、抓抓取色、截图。

exe
下载 tapsprite.exe

手机 App

Android / 模拟器。开无障碍后就能被电脑控制。

apk
下载 tapsprite.apk

怎么用

  1. 电脑打开 tapsprite.exe（SmartScreen 点「仍要运行」）。
  2. 手机或模拟器安装 App，打开后开无障碍。
  3. 电脑左侧选出设备。无障碍已开后就可以下发脚本、截图。
  4. 抓抓页截当前屏幕，取色、记坐标。颜色是手机屏幕的 BGR 十六进制，不要加 #。

坐标原点：屏幕左上角，向右 x、向下 y。脚本分辨率按你写的来，现在常用 1080×2400。

命令说明
Tap(x, y)点一下
Tap2(x, y)连点两次
RandomTap(x, y, r)半径内随机点
LongClick(x, y) / Touch(x, y)长按
Swipe(x1,y1,x2,y2,ms)滑动，默认 300ms
KeyPress("Back")Home / Back / Recents / Notifications / Power / VolumeUp / VolumeDown / Screenshot
InputText("字")当前输入框填字
ClickText("确定")按无障碍节点文本点
Delay(ms) / Sleep(ms)等待
TracePrint("msg")打到电脑日志
Tip("msg")手机底部提示 + 日志，不弹窗
ExitScript()结束
GetPixelColor(x, y)返回 CC7B00
FindColor(x1,y1,x2,y2,color,sim,dir)Lua 返回 x,y，失败 -1,-1
CmpColor(x,y,color,sim)该点是否匹配
WaitColor(..., timeoutMs, sim)等到出现或超时
KeepScreen(true/false)冻结画面再连续找色
OcrText(x1,y1,x2,y2)区域内识字
GetScreenX() GetScreenY()宽高
TickCount()开机毫秒
KeepAwake(true)尽量保持亮屏
GetClip() SetClip("字")剪贴板
RunApp("包名")启动应用

颜色 6 位十六进制，可带容差 CC7B00-030303。sim：0/1 精确，0.9 约 10%，≥2 当通道差。

Lua

引擎是 Lua 5.2。整除请用 math.floor(w / 2)，不要写 //。

local w = GetScreenX()
local h = GetScreenY()
TracePrint("屏幕 " .. w .. "x" .. h)

for i = 1, 5 do
  RandomTap(math.floor(w / 2), math.floor(h / 2), 30)
  Delay(400 + math.random(200))
end

local x, y = FindColor(0, 0, w, h, "CC7B00", 0, 0)
if x > -1 then
  Tap(x, y)
else
  Tip("没找到")
end
